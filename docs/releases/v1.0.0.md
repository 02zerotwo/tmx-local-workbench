# TMX Forge v1.0.0

TMX Forge 1.0 是桌面应用启用新品牌后的首个正式版本，提供本地 TMX 编辑、AI 会话与审查的一体化工作流。

## 主要更新

- 全新的 TMX Forge 应用名称、图标和桌面包标识。
- AI 会话和审查支持编辑修改建议；已经应用的建议会锁定，避免重复编辑。
- 编辑模式与 AI 模式改为整块右侧工作区切换，并为切换按钮提供悬浮提示。
- 右侧工具栏压缩为自适应单行布局，空间不足时自动收纳到“更多”菜单。
- API Key 改为弹窗管理，支持直接替换现有 Key。
- AI 会话支持新建、重命名和删除，默认使用用户第一条消息作为标题并自动截断。
- 保留 TMX 导入、筛选、编辑、历史记录、Excel/TMX 导出和数据库备份恢复能力。
