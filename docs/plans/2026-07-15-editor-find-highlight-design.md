# 编辑器查找高亮与首字母大写设计

## 目标

让当前译文编辑框的查找行为接近 VS Code：输入查询时不跳转，确认后再执行；支持大小写匹配、全部匹配高亮、循环定位，并提供将选中区域首个英文字母转为大写的操作。

## 交互

- 查找输入框维护未提交草稿，输入时清空旧结果但不移动编辑器光标。
- 按 Enter 或点击查找按钮后提交查询并定位第一个结果；Shift+Enter 继续用于输入跨行查询。
- 大小写按钮默认关闭。查询已提交时切换该按钮会立即按新规则重新计算并定位首项。
- 上一个、下一个按匹配范围循环定位；计数显示当前项和总数。
- 普通匹配使用黄色背景，当前匹配使用更深的橙黄色背景。
- 替换当前和全部替换使用已经提交的查询及当前大小写规则。
- 首字母大写按钮只修改目标译文选中区域中遇到的第一个 ASCII 英文字母，保留选区、前方空格、引号和标点；没有选区时不修改。
- 目标文本工具栏和查找面板操作按钮均提供明确的悬停提示。

## 实现

保留原生 textarea，避免破坏输入法、撤销、自动保存和无障碍行为。在 textarea 下方叠放只读镜像文本层，按匹配范围渲染 mark 元素；textarea 保持透明背景并显示真实文字，镜像层跟随其滚动位置。查找逻辑使用包含起止位置的字面量匹配范围，大小写不敏感模式通过转义后的 Unicode 正则表达式完成。

## 验证

- 组件测试覆盖延迟提交、按钮提交、大小写切换、跨行查询、匹配高亮、循环定位、大小写替换及首字母大写。
- 运行编辑器测试、完整测试、ESLint 和 TypeScript 检查。
