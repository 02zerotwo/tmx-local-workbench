# AI 右侧工具栏单行布局设计

## 目标

压缩右侧 AI 面板顶部层级，把当前三层工具栏合并为一条单行工具栏，优先保留高频操作，并根据右侧面板自身宽度把低频操作自动收进“更多”菜单，为聊天内容释放垂直空间。

## 单行工具栏

工具栏左侧固定显示“会话 / 审查”紧凑切换按钮。会话页右侧固定显示“新建会话”，并按空间依次展示当前会话名称、历史、Key 设置；审查页不展示会话相关操作，仅保留 Key 设置。

移除独立的 “DeepSeek Agent” 标题、Key 掩码标题栏和会话内部标题栏。工具栏图标按钮统一使用 `icon-sm`，通过 `aria-label`、`title` 和 Tooltip 保持可发现性。

## 响应式优先级

响应式判断基于右侧 AI 面板容器宽度，不依赖浏览器视口：

1. 宽布局：会话名、历史、新建会话、Key 设置全部直接展示。
2. 中等布局：Key 设置进入“更多”菜单；会话名、历史、新建会话保留。
3. 紧凑布局：历史和 Key 设置进入“更多”菜单；会话名进一步隐藏；会话/审查和新建会话保持常驻。

使用 CSS container query 控制同一套控件的显隐，避免监听窗口宽度或维护额外 React 派生状态。

## Key 设置弹窗

点击 Key 设置后打开弹窗，展示当前 Key 掩码和连接状态，并提供：

- 验证当前连接；
- 输入新 Key 并替换；
- 删除当前 Key，删除前保留二次确认。

未配置 Key 时仍保留现有首次配置引导；配置完成后进入新的单行工具栏。

## 组件边界

- 新增共享 `AiCompactToolbar`，负责模式切换、响应式显隐和更多菜单。
- `AgentConversation` 继续拥有会话列表、当前会话、历史抽屉与新建逻辑，通过 render prop 把会话工具栏状态交给共享工具栏，避免把会话数据上提到 AI 设置容器。
- `AiModePanel` 负责模式状态、Key 设置弹窗，以及在会话/审查页组合共享工具栏。
- `AuditPanel` 保持审查业务逻辑不变，仅由外层提供工具栏。

## 测试

- 已配置状态不再显示 “DeepSeek Agent” 标题和 Key 掩码顶栏。
- 单行工具栏同时包含模式切换和会话高频操作。
- 点击 Key 设置打开弹窗，可验证、替换和触发删除确认。
- 会话历史与新建会话行为保持不变。
- 响应式 CSS 包含宽、中、窄三档容器规则，隐藏控件在对应“更多”菜单中仍可访问。
